# フォルダスライドショー

パソコンのフォルダを選ぶと、中の画像と動画を順に大きく映す。**HTML 1枚。サーバーもビルドも無い。**

**https://haristweet.github.io/slideshow/**

## 使いかた

**フォルダを選ぶか、画面にドラッグ＆ドロップする。** サブフォルダの中まで読む。
あとは勝手に流れる。画面をクリックで一時停止。

| | キー |
|---|---|
| 再生 / 一時停止 | `Space`（画面クリックでも可） |
| 次へ / 前へ | `→` `←`（`J` `K` でも可） |
| フルスクリーン | `F` |
| シャッフル | `S` |
| 画面に合わせる ⇄ 画面いっぱい | `C` |
| 文字と操作盤を消す | `H` |

2.5秒さわらないと操作盤が自動で消える。表示秒数・並び順・シャッフル・表示方法は
次に開いたときも覚えている。

## 映せるもの

- **画像** — jpg / png / gif / webp / avif / heic / svg / bmp
- **動画** — mp4 / webm / mov（最後まで再生してから次へ進む）

heic と mov は Safari だと確実に映る。Chrome は heic を表示できないことがある。

## 並べかた

名前順（`2` と `10` を数字として並べる自然順）／更新日順／更新日の新しい順／シャッフル。
表示は1〜30秒で変えられる。切り替えはクロスフェードで、次の画像は先に読み込んでおく。

## ファイルはどこにも送っていない

読み込みも表示も全部ブラウザの中で完結している。アップロードは無い。
Chrome でフォルダを選ぶと「アップロードしますか」と確認が出るが、これはブラウザの決まり文句で、
実際に外へ出るものは無い。

## パスを指定して開けない理由

ブラウザは、安全のため `~/Pictures` のようなパスを勝手に読むことができない。
**必ず1回は自分でフォルダを選ぶ必要がある。** その代わり、置くだけで動く。
