# フォルダスライドショー

パソコンのフォルダを選ぶと、中の画像と動画を順に大きく映す。**HTML 1枚。サーバーもビルドも無い。**

**https://haristweet.github.io/slideshow/**

## 使いかた

**フォルダを選ぶか、画面にドラッグ＆ドロップする。** サブフォルダの中まで読む。
あとは勝手に流れる。画面をクリックで一時停止。

| | キー |
|---|---|
| 再生 / 一時停止 | `Space`（画面クリックでも可） |
| 次へ / 前へ | `→` `←`（`J` `K` でも可） |
| 縦長を左右に並べる | `P` |
| フルスクリーン | `F` |
| 音を消す / 出す | `M` |
| 音量 | `↑` `↓` |
| ASMRモード | `A` |
| 一覧を見る | `G`（戻るのは `G` か `Esc`） |
| サムネイルの大小 | 一覧で `−` `＋` ・ ⌘＋ホイール |
| メモを開く / 閉じる | `N` |
| 拡大 / 縮小 | マウスのホイール |
| 拡大したまま動かす | ドラッグ |
| 等倍に戻す | `0`（ダブルクリックでも可） |
| シャッフル | `S` |
| 画面に合わせる ⇄ 画面いっぱい | `C` |
| 文字と操作盤を消す | `H` |

2.5秒さわらないと操作盤が自動で消える。表示秒数・並び順・シャッフル・表示方法は
次に開いたときも覚えている。

## 縦長を左右に並べる

**`P` を押すと、縦長の画像を横に並べて画面を埋める。** 16:9 のディスプレイに縦長写真を
1枚だけ映すと左右が大きく余るが、2枚並べればほぼ埋まる。

**何枚並べるかは、ディスプレイと画像の縦横比から決まる。** 画面の横幅に画像の横幅が
いくつ入るかを計算するだけで、16:9 に 2:3 の写真なら2枚、ウルトラワイド（21:9）に
スマホ写真（9:16）なら3枚。縦長ディスプレイでは並べない。ウィンドウの形を変えると
その場で計算し直す。

**並ぶのは、連続した縦長画像だけ。** 横長や動画は今までどおり1枚で映る。
組の区切りは「連続した縦長の並びの先頭」から数えるので、`←` で戻っても同じ組み合わせになる。

## どこで見るのをやめたかを記録する

**閉じたとき・別のタブに移ったときに、そのとき映っていた写真を書き留める。** 次に同じ
フォルダを開くと、**その続きから再生**して「前回はここで終わっていました」と上に出る。
最初から見たいときは、そのバーの **最初から** を押す。

記録している内容は、日時・フォルダ名・ファイル名・何枚目か・総数・そのとき何枚見たか・
何秒見ていたか・再生中だったか・きっかけ（閉じた／画面を離れた／フォルダを変えた）。

**最初の画面の「中断の記録を見る」から一覧できる。** **CSVで書き出す** で Excel に
そのまま渡せる（BOM付きUTF-8）。**記録を消す** で全部消える。直近300件まで残る。

同じ写真のまま出たり入ったりしただけのときは、件数を増やさずに上書きする。

### 記録はこの端末のこのブラウザにしか残らない

ブラウザの localStorage に入れているだけなので、どこにも送信されない。その代わり、
**開き方が変わると別の記録になる**（デスクトップのファイルと公開版の URL では別々、
Safari と Chrome でも別々）。実測を続けるなら、開き方を1つに決めた方がいい。
プライベートウィンドウなど保存できない状況では、最初の画面にその旨を出す。

## 一覧を見る

**`G` で一覧（サムネイルの格子）に切り替わる。** 押したものからスライドショーに戻る。
音声ファイルも並ぶ。

**サムネイルは横320pxに焼き直して取っておく。** 元の写真をそのまま縮めて並べると、150pxの
タイルのために毎回フルサイズで展開することになる（2400×1600 の写真なら51万画素が6.8万画素に
なる勘定）。焼いたものは IndexedDB にも入れるので、**次に同じフォルダを開いたときは作り直さない**。
元のファイルの大きさと更新日時を鍵にしているので、差し替えたファイルだけ作り直す。
絞り込みや検索でもタイルを使い回すため、並べ替えで作り直しは起きない。

**サムネイルの大きさは変えられる。** 上のスライダー、`−` `＋` キー、⌘（Ctrl）＋ホイールの
どれでも。90〜360px のあいだで、小さくすると一度にたくさん見渡せる（130px より小さいときは
ファイル名を隠して詰める）。次に開いたときも覚えている。

### ファイル名とは別に名前を付けられる

**名前をクリックすると書き換えられる。** 付けた名前はスライド表示中も優先して出て、
元のファイル名は小さく併記される。ファイルそのものには手を触れない。

名前は**フォルダ名＋フォルダ内の道順**に紐づけて、このブラウザに保存される。ファイルを
動かしたり名前を変えたりしなければ残る。**CSVで書き出して読み込める**ので、Excel で
まとめて付けてから戻したり、別のブラウザへ引き継いだりできる（書き出しは `フォルダ /
ファイル / 名前 / お気に入り / 順番 / タグ / メモ` の7列。改行を含むメモもそのまま行き来する）。

### メモとタグ

**サムネイルの右下にある ✎ を押すと、右側に引き出しが開く。** そこで名前・タグ・メモを書く。
書いたものはすぐ保存される。`←` `→` で隣のファイルへ移れるので、続けて書いていける。

**メモを書いたものは ✎ の印が青く点く。** 書いていないものの ✎ は、カーソルを乗せたときだけ
薄く出る。一覧が印だらけにならず、書いたものだけが目に入る。

**スライド中は、左上にタグと「✎ メモ」の札が出るだけ。** 読みたくなったら `N` か札を押すと
本文が開く。開いたまま次へ送れば、そのファイルのメモに入れ替わる。メモの無いファイルでは
自動で閉じる。`H` で消す文字と一緒に引っ込む。

**タグは読点・カンマ・空白のどれで区切ってもいい。** 左側にタグの一覧が数つきで出て、
押すと絞り込める。複数選ぶと、その全部が付いているものだけになる。

**検索はメモとタグの中身にも当たる。** 「三脚」と打てば、メモに三脚と書いたファイルが出る。

### 絞り込みと並べ替え

- **フォルダツリー** — 左の一覧でフォルダを選ぶとそこだけになる。下の階層もまとめて入る
- **検索** — 付けた名前でもファイル名でも、打った字で絞り込む
- **★** — 気に入ったものに付けて、**★だけ再生**できる
- **選択** — 左上の四角で選んで、**選んだものだけ再生**できる
- **ドラッグで並べ替え** — 動かすと並び順が「自分の順番」になり、その順で再生する

**一覧で見ていた状態のまま再生に移る。** フォルダを選んで押せばそのフォルダだけ、
★表示のまま押せば★だけが順に流れる。**この並びで再生**でも同じことができる。

## ASMRモード

**同じフォルダに音声ファイルが入っていれば、それを流しながら絵を送る。** `A` で切り替え。
音声があるフォルダを開くと「音声が◯件あります」と一度だけ出る。

- **絵は表示秒数で送りつつ、音が1本終わった時点でも切り替える。** 長い音源でも画面が止まらず、
  音の切れ目と絵の切れ目が必ず合う
- **音を全部鳴らし終わったら最初に戻って繰り返す。** かけっ放しにできる
- **動画は消音して繰り返す「動く絵」として扱う。** 音声と取り合いにならない
- 音声の並び順は絵と同じ設定（名前順／更新日順／シャッフル）に従う
- 再生中の曲名と残り時間を左上と操作盤に出す。`M` と `↑` `↓` は音声にも効く
- 中断の記録には、そのとき鳴っていた音声のファイル名も残る

対応形式は mp3 / m4a / aac / wav / flac / ogg / opus / aiff。再生できない形式のときは
名前を出して次の音へ進む。音声ファイルは絵としては出てこない。

## ホイールで拡大する

**カーソルを合わせてホイールを回すと、その部分が大きくなる。** カーソルの下にある点は
動かないので、見たいところに合わせて回せばそこへ寄っていく。等倍から8倍まで。
写真の外（左右の黒い余白）で回しても効く。
**ドラッグで動かせる。** 枠の内側が空いてしまう位置までは動かない。

**等倍に戻すのは `0`、またはダブルクリック。** 次の写真へ送っても等倍に戻る。

写真も動画も**画面に合わせて表示する**（画面より小さいものは引き伸ばす）。拡大して見える
範囲は画面いっぱいなので、小さい動画でも縦長に切り取られたりしない。動かせるのは映像の
端までで、その外側の黒い部分は入ってこない。

**拡大している間は自動送りを止める。** 見ている最中に次へ流れていかないため。等倍に
戻すと自動送りも戻る。縦長を左右に並べているときは、**カーソルの下にある1枚だけ**が
大きくなり、隣にはみ出さない。

## 動画

**動画があれば音つきで再生し、最後まで流してから次へ進む。** 一時停止中は勝手に始まらない。
再生中は上の帯が動画の再生位置を表し、操作盤に残り時間が出る。

`M` で消音、`↑` `↓` で音量。設定は次に開いたときも覚えている。ブラウザに音つきの
自動再生を止められた場合は、消音で流しながら「クリックすると音が出ます」と出すので、
一度どこかを押せば音が出る。

**再生できない動画は、黙って飛ばさずに理由を出す。** ファイル名と「このブラウザが
対応していない形式です」を数秒出してから次へ進む。`←` で戻っている最中なら、
前へ弾き返さずにそのまま戻る方向へ抜ける。

## 映せるもの

- **画像** — jpg / png / gif / webp / avif / heic / svg / bmp
- **動画** — mp4 / webm / mov / m4v / ogv

heic と、iPhone で撮った mov（HEVC）は Safari なら確実に再生できる。Chrome は
どちらも開けないことがあり、そのときは上の理由表示が出る。

## 並べかた

名前順（`2` と `10` を数字として並べる自然順）／更新日順／更新日の新しい順／シャッフル。
表示は1〜30秒で変えられる。切り替えはクロスフェードで、次の画像は先に読み込んでおく。

## ファイルはどこにも送っていない

読み込みも表示も全部ブラウザの中で完結している。アップロードは無い。
Chrome でフォルダを選ぶと「アップロードしますか」と確認が出るが、これはブラウザの決まり文句で、
実際に外へ出るものは無い。

## パスを指定して開けない理由

ブラウザは、安全のため `~/Pictures` のようなパスを勝手に読むことができない。
**必ず1回は自分でフォルダを選ぶ必要がある。** その代わり、置くだけで動く。
